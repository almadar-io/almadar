# Prispevanje k Almadarju

Pozdravljamo prispevke iz skupnosti!

## Načini prispevanja

- **Prijavi napake** - Odpri issue na GitHubu
- **Predlagaj funkcije** - Začni razpravo
- **Pošlji PR** - Popravi napake ali dodaj funkcije
- **Piši dokumentacijo** - Izboljšaj dokumentacijo
- **Deli** - Povej drugim o Almadarju

## Prvi koraki

1. Fork repository
2. Ustvari feature branch
3. Naredi svoje spremembe
4. Pošlji pull request

## Skupnost

- [GitHub Discussions](https://github.com/almadar-io/almadar/discussions)
- [Discord](https://discord.gg/almadar)
