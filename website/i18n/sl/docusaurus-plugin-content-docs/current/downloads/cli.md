# Almadar CLI

Almadar Command Line Interface (CLI) je vaš vstop v Almadar ekosistem.

## Namestitev

### npm (Priporočeno)

```bash
npm install -g @almadar/cli
```

## Ukazi

| Ukaz | Opis |
|---------|-------------|
| `almadar new` | Ustvari nov projekt |
| `almadar validate` | Validiraj shemo |
| `almadar compile` | Prevedi v target shell |
| `almadar dev` | Zaženi dev strežnik |
| `almadar test` | Poženi state machine teste |
| `almadar format` | Formatiraj shemo |

## Hiter začetek

```bash
# Ustvari nov projekt
almadar new my-app

# Pomakni se v projekt
cd my-app

# Zaženi razvoj
almadar dev
```
